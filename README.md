# ChampionLED «Победа»

HTML-прототип лендинга магнитной трековой системы 48 В. Фирменный стиль ChampionLED, согласованная структура Про/Эко и реальные изображения действующего лендинга.

## Просмотр и редактирование

Откройте `index.html` или `ChampionLED_Pobeda_HTML_prototype.html` в браузере. Изображения и шрифты встроены; интернет нужен только для перехода на внешние страницы товаров и LEDMONSTER. Инструкции лежат в `docs/`.

HTML, CSS и JavaScript доступны для редактирования непосредственно в файле. Сборка не требует установки библиотек.

## Состав страницы

Первый экран → сравнение Про/Эко → товары → модели и фильтр по типу света → качество света → монтаж и схемы соединения Про/Эко → отдельный блок установки светильника → управление → конфигурация → документы → применение в интерьере → обращение в LEDMONSTER → FAQ.

Фотографии, логотип и шрифты — из действующего сайта ChampionLED. Схема соединения Эко — из предоставленного каталога. Данные 83 товаров и цены получены из Яндекс Кита 05.11.2026.

## Ограничения прототипа

Корзина работает только в памяти страницы, не создаёт заказов и не принимает оплату. Комплектующие выбираются пользователем; автоматический инженерный расчёт не реализован. Варианты, для которых не определён подходящий товар, блокируют добавление состава. «Печать / PDF» использует печать браузера с отдельным оформлением состава.

Проектная консультация вынесена в LEDMONSTER. Покупка отдельных товаров ведёт на реальные карточки ChampionLED.
