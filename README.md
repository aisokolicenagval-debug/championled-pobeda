# ChampionLED «Победа»

HTML-прототип лендинга магнитной трековой системы 48В.

**Просмотр:** https://aisokolicenagval-debug.github.io/championled-pobeda/

## Что входит

Первый экран и пять УТП; сравнение Про/Эко; товары из снимка каталога; слайдер шести моделей с фильтрами по типу света; качество света; монтаж и переключаемые схемы соединения; магнит и скрытый механический замок; управление; характеристики и документы; для дома и бизнеса; кейсы; обращение в LEDMONSTER; FAQ.

Выполнена адаптация для телефонов и планшетов. Изображения и шрифты встроены в HTML. Крупные схемы лежат в `assets/`, инструкции — в `docs/`.

## Исходники и сборка

Исходники находятся в `source/`. Нужен Python 3, сторонние библиотеки не требуются:

```sh
python3 source/build_final.py
```

Результат появится в `source/final/`. Для публикации скопируйте оба HTML-файла и каталог `assets/` из результата сборки в корень репозитория. GitHub Pages публикует корень ветки `main`.

Основные файлы: `logic/landing.html` — содержание; `final-style.css` и `layout-system.css` — оформление; `light-slider.js` — слайдер; `hero_content.py`, `installation_section.py`, `control_section.py` — блоки страницы; `document-request-dialog.html` и `document-request.js` — форма. `final-assets/embedded.json` содержит сохранённые публичные материалы и данные каталога.

## Ограничения прототипа

Это прототип для согласования, действующий магазин Яндекс.Кита не изменён. Цены и товары — снимок каталога от 05.11.2026, автоматического обновления в автономном HTML нет. Кнопки товаров ведут на карточки ChampionLED.

Форма запроса документов демонстрационная: проверяет обязательные поля, но не отправляет и не сохраняет данные. Подписи четырёх кейсов пока «Название кейса».

Фоновое изображение первого экрана улучшено с помощью imagegen; исходное изображение сохранено в снимке материалов. Промпт находится в `source/hero-enhancement-prompt.txt`.
