# ChampionLED «Победа»

HTML-прототип лендинга магнитной трековой системы 48В. Фирменный стиль ChampionLED, согласованная структура Про/Эко и реальные изображения действующего лендинга.

## Просмотр и редактирование

Откройте `index.html` или `ChampionLED_Pobeda_HTML_prototype.html` в браузере. Изображения и шрифты встроены; интернет нужен только для перехода на внешние страницы товаров и LEDMONSTER. Инструкции лежат в `docs/`, крупные схемы — в `assets/`.

HTML, CSS и JavaScript доступны для редактирования непосредственно в файле. Сборка не требует установки библиотек.

## Состав страницы

Первый экран → сравнение Про/Эко → товары → модели и четыре фильтра по типу света → качество света → монтаж и схемы соединения Про/Эко → отдельный блок установки светильника → управление → документы → применение в интерьере → обращение в LEDMONSTER → FAQ.

Про/Эко и категории выровнены в компактной группе без фоновой плашки. Кнопки Про/Эко прозрачные, выбранное исполнение отмечено контуром. Товарные категории: светильники, шинопроводы, комплектующие, питание.

Фотографии, логотип и шрифты — из действующего сайта ChampionLED. Схема соединения Эко — из предоставленного каталога. Данные 83 товаров и цены получены из Яндекс Кита 05.11.2026.

## Текущая итерация

Конфигуратор, демонстрационная корзина и печать состава удалены. Покупка компонентов ведёт на реальные карточки ChampionLED. Управление освещением описано в отдельном информационном блоке. Проектная консультация вынесена в LEDMONSTER.

## Яндекс Кит

Публикация служит для проверки дизайна и содержания. Это не опубликованная версия витрины Яндекс Кита; действующий магазин не изменяется.

В блоке «Купить компоненты» показан образец штатной товарной полки Яндекс.Кита: фото, названия, цены и ссылки из сохранённого снимка каталога. Автоматическое обновление данных выполняется штатной полкой на витрине Кита; автономный HTML содержит снимок данных.
